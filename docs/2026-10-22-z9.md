# Z9 — «Настройки»: одна структура, одна панель сохранения

## Сделано
- **Панель сохранения.** Обычные настройки правятся на месте, кнопок «Сохранить» в секциях нет. При первом изменении появляется липкая панель «Есть несохранённые изменения · Отменить · Сохранить».
  - «Сохранить» — один PATCH и одна транзакция на бэкенде: новая функция `save_tenant_settings_bundle` пишет в `tenants`, `assistant_profiles` и `notification_settings`.
  - Панель исчезает только после ответа сервера: сначала 3 с «✓ Сохранено». При ошибке остаётся «Не сохранено · Повторить», введённые значения не сбрасываются.
  - У секции с изменениями — точка у заголовка.
  - Уход со страницы спрашивает «Уйти без сохранения?»: ссылки меню, «назад», закрытие вкладки.
  - На телефоне панель стоит над нижним меню и над клавиатурой (`visualViewport`). Активное поле прокручивается выше панели (`scroll-margin`).
- **Секции:** Ассистент · Бизнес · Связь с вами · Когда не беспокоить · WhatsApp · Аккаунт. Идут подряд, аккордеона нет. Колонка до 640 px, высота полей 40/44 px. Старые ссылки `?section=phone|schedule` открывают новые секции.
- **Номер владельца.**
  - В покое: «+972 52-369-5741 · ✓ Подтверждён».
  - «Изменить»: код страны (+972) и номер. Ввод «052…», «52…», «972…», «+972…» приводится к E.164 и сразу показывается в едином виде.
  - Новый номер ждёт подтверждения в `pending_owner_phone`. До подтверждения вопросы и заявки идут на прежний номер. Бэкенд принимает код только с нового номера.
- **«Не беспокоить».** Переключатель и «с … до …». Пустые значения в БД — переключатель выключен.
  - Одинаковые часы не сохраняются ни в кабинете, ни на бэкенде (код `quiet_hours_equal`).
  - Ночной интервал показывается как «22:00 – 08:00 (до утра)». Ниже — исключения.
- **Часовой пояс:** «Иерусалим · сейчас 14:53», меняется сразу при выборе.
- **Аккаунт:** email, «Сменить пароль» (раскрывается по кнопке), тариф, «Выйти» красным текстом. Роли, даты и языка кабинета нет.
- **WhatsApp в «Настройках»:** статус и номер, «Переподключить» (контурная кнопка, только когда связь не работает), строка о риске частого переподключения, «Отключить» красным текстом.
- **Главная.** Карточка WhatsApp в одну колонку, номер бизнеса один раз. Телефон владельца показывается, только когда нужно действие: строка-предупреждение и «Указать номер» → «Связь с вами».
- **Словари.** Добавлены тексты ru/he/en, неиспользуемые ключи удалены (около 50 ключей × 3 языка). Заголовок «Аккаунт» на иврите — «החשבון».

## Найденные причины
- **Две настройки тихих часов.** Тихие часы в блоке телефона (`quiet_hours_*`) не действовали, если было сохранено недельное расписание (`behavior.weekly_schedule`): расписание их перекрывало (`isWithinQuietHours`). Сейчас «Не беспокоить» — единственная настройка. При её сохранении `weekly_schedule` очищается. В проде расписание задано только у одного тенанта, и там все дни «весь день», так что поведение не меняется.
- **«12:30» при null в БД.** API отдавал пустые строки, значение не подставлялось. В коде причина не найдена: вероятно, это пустое нативное поле времени, в котором браузер рисует заглушку. Сейчас при пустых значениях поля не показываются вовсе.

## Не сделано / отличия от задания
- **«Переподключить» при работающем WhatsApp не показывается.** Перезапуск живой сессии потребовал бы менять контракт с WAHA.
- **Клавиатура:** проверена эмуляцией 375 px. На реальных iOS Safari и Android Chrome не проверялась — устройства нет.
- **Номер без подключённого WhatsApp** сохраняется сразу, как раньше: код отправить не с чего.
- **Кнопка симулятора** — «Проверить ответы». Это решение Юрия, строку не менял.
- **Тенанты без инструкции:** тон и стиль, приветствия и вопросы-подсказки сохраняются своими кнопками внутри «Ассистента».
- **Недельное расписание** («когда отвечать по дням») из интерфейса убрано по составу секций задания.
